# Contributing

## How to Contribute

Thanks for wanting to help improve this project! To propose a change, create a new branch off the default branch, make your edits, and open a pull request describing what you changed and why. Smaller, focused pull requests are easier to review and land faster, so try to keep each one scoped to a single purpose.

Once your pull request is open, a maintainer will review it — usually within a couple of business days — and may suggest edits, ask clarifying questions, or request changes before approval. After any feedback is addressed and the required checks pass, your pull request will be squash-merged into the default branch.
